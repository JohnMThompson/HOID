# HOID

HOID (Home Office Interface Device) is a planned local-first, personality-driven assistant for a home office, with a possible future workshop presence called WIT (Workshop Interface Technology). The defining interaction is a physical desk phone; ordinary phone calls and physical controls should remain useful without the assistant.

This repository is currently for public-facing project documentation. No application or infrastructure implementation has begun. Local planning notes are kept in `docs/planning/`; that directory is Git-ignored and will not be included in GitHub pushes.
